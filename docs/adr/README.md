# Registros de decisão de arquitetura

Cada registro documenta uma decisão de projeto relevante: o contexto que a motivou, a decisão tomada,
as consequências e as alternativas consideradas. Os registros não são reescritos quando a decisão
muda; um novo registro substitui o anterior e o anterior passa ao estado "Substituído".

| [0003](0003-prioridade-e-expansao-nas-sobreposicoes.md) | Prioridade por tipo e expansão até o limite do token | Aceito |

| [0006](0006-verificacao-final-e-falha-fechada.md) | Verificação final do arquivo e falha fechada | Aceito |
| [0007](0007-propagacao-no-documento.md) | Propagação de valores tarjados no documento | Aceito |

## Modelo

```markdown
# NNNN. Título

- Estado: Proposto | Aceito | Substituído por NNNN
- Data: AAAA-MM-DD

## Contexto
## Decisão
## Consequências
## Alternativas consideradas
```
