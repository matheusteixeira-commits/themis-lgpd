# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha pessoas de todas as origens e níveis de experiência, critique ideias
e não pessoas, e lembre que o objetivo comum é proteger os dados de cidadãos e cidadãs.

Comportamentos inaceitáveis podem ser reportados de forma privada pelo recurso de *Security Advisories*
do repositório ou diretamente aos mantenedores. Toda denúncia será tratada com sigilo.
